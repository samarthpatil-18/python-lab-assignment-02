Python Lab Assignment 02
Find the Largest of Three Numbers
Aim
To write a Python program to find the largest of three numbers.
Objectives
To understand decision-making statements in Python.
To implement `if`, `elif`, and `else`.
To use logical and relational operators.
Problem Statement
Accept three integer numbers from the user and display the largest number.
Concepts Used
`if` statement
`elif` statement
`else` statement
Logical operators: `and`, `or`, `not`
Relational operators: `==`, `!=`, `>`, `<`, `>=`, `<=`
Platform
Python 3
Windows / Ubuntu
IDLE, Jupyter Notebook, or any Python IDE
How to Run
```bash
python python_lab_assignment_02.py
```
Example
```text
Enter the first number: 25
Enter the second number: 48
Enter the third number: 17

The largest number is: 48
```
Algorithm
Start.
Accept three integer numbers from the user.
Compare the first number with the second and third numbers.
If the first number is greater than or equal to both, store it as the largest.
Otherwise, compare the second number with the first and third numbers.
If the second number is greater than or equal to both, store it as the largest.
Otherwise, the third number is the largest.
Display the largest number.
Stop.
Conclusion
Studied and implemented decision-making statements using Python to find the largest of three numbers.
